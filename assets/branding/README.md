# PhoneDex CLI branding

These assets extend the PhoneDex visual identity for the optional CLI project: midnight backgrounds, electric blue-to-violet accents, and the original call-loop mark used in the PhoneDex wordmark. No third-party logo artwork is included.

| Asset | Use |
| --- | --- |
| `hero.jpg` | README header, 1600 × 800. |
| `social-preview.jpg` | GitHub social preview, 1280 × 640. |
| `hero-background.jpg` | Shared abstract wave background. |
| `icon.png` / `icon.svg` | Square avatar and app icon. |
| `wordmark-on-dark.svg` | Transparent wordmark for dark backgrounds. |
| `wordmark-on-light.svg` | Transparent wordmark for light backgrounds. |
| `architecture.svg` | README and docs integration diagram. |

The SVG wordmarks use the PhoneDex call-loop glyph as the actual `o`. PhoneDex CLI is an independent companion project; it is not endorsed by or affiliated with OpenAI, Codex or AgentPhone.
